# Greek Vocab

This repository is a repository of experiments using Ancient Greek vocabulary (from homeric to koine)

The scripts contains some python scripts and csv files. 
- The file gold_standard_verbs.csv come from the repository [Gold Standard Verbs](https://bitbucket.org/ben-crowell/gold_standard_verbs/src/master/)
- The files NT_Greek_Master_Unique.csv and NT_Greek_Master.csv both come from the website [Greek New Testament Database](https://greekntdatabase.github.io/NTGreekDatabase/index.html)
- THe file athenaze-vocab.csv come from the spreadsheet found in the following Reddit post [Athenaze Vocabulary](https://www.reddit.com/r/AncientGreek/comments/thv8k2/italian_athenaze_vocabulary_with_english_glosses/)
- All other non specified files are generated by me

## Project 1 - Transcription and buildup of vocabulary using a Greek Reader

Using the texts from the 1905 book "A Greek Reader for schools", this project is building a React Native app where one can read the texts, see more common words and build up vocabulary using flashcards. See the Project's [Tasks](project1-tasks.md)
